# Changelog

## 0.1.0 — 2026-09-26
- Initial reusable skill specification.
- Added address-first site resolution with non-invented parcel behavior.
- Added adjustable/manual GPS AOI fallback.
- Added progressive-fidelity model (L0/L1/L2).
- Added terrain, hydrology, solar, soils, earthworks, and permaculture analysis layer contracts.
- Added provenance/uncertainty requirements, JSON schemas, and acceptance criteria.

## 0.2.0 — 2026-10-10

- Delegate the four DEM-based Google Earth-style terrain-analysis layers to reusable `terrain-site-analysis` skill.
- Retain provenance, AOI/analysis-buffer distinctions, and explicit Unverified status until real data are acquired.
