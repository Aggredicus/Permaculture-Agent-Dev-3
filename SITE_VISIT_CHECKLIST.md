# Site Visit Checklist

Use this checklist during a field visit. Record observations carefully and mark uncertain items as unknown rather than guessing.

## Before Arrival

- [ ] Confirm appointment time and site address.
- [ ] Review intake form.
- [ ] Review existing maps, screenshots, surveys, or photos.
- [ ] Prepare base map or blank field sketch.
- [ ] Bring measuring tools, phone/camera, notebook, flags, compass, tape, soil probe/trowel if appropriate.
- [ ] Check weather and recent rainfall.
- [ ] Ask client about pets, livestock, gates, hazards, and parking.

## Client Walkthrough

- [ ] Ask client to walk the site in their normal use pattern.
- [ ] Ask where they spend time.
- [ ] Ask where maintenance feels frustrating.
- [ ] Ask where water collects or runs.
- [ ] Ask what areas they love.
- [ ] Ask what areas they avoid.
- [ ] Ask about neighbor issues, privacy, noise, views, and access.
- [ ] Ask about previous attempts, failures, or plant losses.

## Base Map Verification

- [ ] Confirm north direction.
- [ ] Confirm rough boundary or working design area.
- [ ] Mark boundary uncertainty.
- [ ] Verify structures and access points.
- [ ] Mark driveways, gates, paths, fences, and utilities if known.
- [ ] Mark wells, septic, drains, culverts, downspouts, and outlets if known.
- [ ] Mark major existing trees and vegetation patches.
- [ ] Note areas missing from the base map.

**Reminder:** Do not assume property boundaries. Do not treat informal maps as survey-grade.

## Boundary / Access / Infrastructure

Photograph and note:

- [ ] Driveway and parking
- [ ] Main entrances
- [ ] Service/delivery access
- [ ] Gates and fences
- [ ] Existing paths
- [ ] Buildings and rooflines
- [ ] Downspouts and gutters
- [ ] Outdoor water sources
- [ ] Power lines and utility markers
- [ ] Septic/well locations if known
- [ ] Storage and work areas
- [ ] Equipment access limits

## Water Observations

- [ ] Roof runoff direction
- [ ] Driveway runoff
- [ ] Low spots and ponding
- [ ] Erosion channels
- [ ] Sediment deposits
- [ ] Wet/dry plant indicators
- [ ] Existing ditches, drains, culverts, streams, ponds, or wetlands
- [ ] Areas that may receive neighbor runoff
- [ ] Possible overflow routes
- [ ] Potential rain garden or infiltration zones

Questions to ask:

- Where does water stand after heavy rain?
- How long does it stay?
- Any basement, foundation, driveway, or neighbor drainage issues?
- Any seasonal wetness or drought stress?

**Hard reminder:** Water interventions need safe overflow paths.

## Soil Observations

- [ ] Texture estimate: sand / loam / clay / mixed / unknown
- [ ] Compaction signs
- [ ] Organic matter indicators
- [ ] Bare soil
- [ ] Erosion
- [ ] Drainage indicators
- [ ] Existing mulch or leaf litter
- [ ] Soil life indicators
- [ ] Contamination concerns
- [ ] Soil test available or needed

Optional quick checks:

- Observe soil at several locations.
- Note color, smell, texture, moisture, compaction, roots, worms.
- Avoid making nutrient claims without testing.

## Sun / Shade / Microclimate

- [ ] Full sun areas
- [ ] Morning sun areas
- [ ] Afternoon sun areas
- [ ] Partial shade
- [ ] Deep shade
- [ ] South/west heat reflection
- [ ] Frost pockets
- [ ] Wind-exposed areas
- [ ] Sheltered areas
- [ ] Warm walls or heat sinks
- [ ] Cold air drainage pathways

Photograph shade patterns if possible.

## Slope / Landform

- [ ] High points
- [ ] Low points
- [ ] Ridges
- [ ] Valleys or swales
- [ ] Steep slopes
- [ ] Gentle slopes
- [ ] Concave water-collecting areas
- [ ] Convex shedding areas
- [ ] Erosion-prone slopes
- [ ] Possible contour/keyline opportunities

Flag professional review for high-risk earthworks or slopes near structures.

## Existing Vegetation

- [ ] Major trees
- [ ] Shrubs
- [ ] Lawn areas
- [ ] Existing gardens
- [ ] Weedy/invasive patches
- [ ] Wetland/riparian indicator plants
- [ ] Pollinator plants
- [ ] Wildlife habitat features
- [ ] Deadwood/snags if safe
- [ ] Diseased or hazardous trees

Photograph:

- tree canopy
- trunk/base of major trees
- understory patches
- invasive species
- areas proposed for change

## Wildlife and Pest Pressure

- [ ] Deer browse
- [ ] Rabbit damage
- [ ] Vole/rodent tunnels
- [ ] Geese/duck pressure
- [ ] Insect damage
- [ ] Disease signs
- [ ] Neighbor pets
- [ ] Livestock impacts
- [ ] Wildlife corridors

Ask client:

- What gets eaten?
- What animals do you commonly see?
- Are deer fences, repellents, or tree tubes acceptable?

## Human Use Patterns

- [ ] Daily paths
- [ ] Work routes
- [ ] Play areas
- [ ] Gathering spaces
- [ ] Views to preserve
- [ ] Views to screen
- [ ] Noise sources
- [ ] Privacy concerns
- [ ] Storage needs
- [ ] Compost/waste flow
- [ ] Accessibility needs
- [ ] Maintenance bottlenecks

## Safety / Utilities / Hazards

- [ ] Overhead wires
- [ ] Underground utilities unknown
- [ ] Wells/septic unknown
- [ ] Poisonous plants
- [ ] Hazardous trees
- [ ] Steep slopes
- [ ] Wet/slippery areas
- [ ] Unsafe structures
- [ ] Traffic/road hazards
- [ ] Chemical storage or contamination concern
- [ ] Regulated water/wetland/shoreline concern

**Reminder:** Verify utilities before digging.

## Photos and Documentation

Capture:

- [ ] Four cardinal-direction site photos
- [ ] House/building sides and roof runoff
- [ ] Downspouts and drainage paths
- [ ] Wet/eroded/dry areas
- [ ] Existing trees and plant communities
- [ ] Access routes
- [ ] Proposed design areas
- [ ] Hazards and unknowns
- [ ] Photo points for future monitoring

## Measurements to Collect

- [ ] Approximate dimensions of design areas
- [ ] Path widths
- [ ] Distance from structures
- [ ] Tree spacing and canopy spread
- [ ] Downspout outlet locations
- [ ] Slope estimates or contour references
- [ ] Gate/vehicle access widths
- [ ] Available planting bed dimensions
- [ ] Distance to utilities if marked

## Immediate Red Flags

- [ ] Standing water near foundation
- [ ] Uncontrolled erosion
- [ ] Suspected regulated wetland/shoreline work
- [ ] Large earthwork request
- [ ] Unknown utilities in proposed dig area
- [ ] Hazardous tree near people or structures
- [ ] Client wants invasive/toxic/problem plant
- [ ] Maintenance burden exceeds client capacity
- [ ] Budget cannot support desired scope
